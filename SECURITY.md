# Security Policy

The security of MKV Auto is taken seriously.

If you believe you have discovered a security vulnerability, please follow the
guidelines below.

---

## Reporting a Vulnerability

Please do **not** open a public issue for security-related problems.

Instead, report vulnerabilities privately by contacting:

Email: security@mkvauto.com
(or replace with your preferred contact method)

When reporting a vulnerability, please include:
- a clear description of the issue
- steps to reproduce, if applicable
- any relevant logs or screenshots
- your environment (OS, container version, platform)

---

## Disclosure Process

After a report is received:
1. I will acknowledge receipt as soon as reasonably possible.
2. The issue will be investigated.
3. If confirmed, a fix will be developed and released.
4. Public disclosure will occur after a fix is available, when appropriate.

---

## Scope

This policy applies to:
- the MKV Auto application
- its containerized runtime
- official release artifacts

It does not apply to:
- modified or unofficial builds
- third-party dependencies beyond reasonable control

---

Thank you for helping keep MKV Auto secure.
