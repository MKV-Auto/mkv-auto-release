# Contributing to MKV Auto

First — thank you for taking the time to look at MKV Auto.

This project exists to lower the barrier to entry for people who want to
digitize their personal media collections. It is also a personal project that
I maintain end-to-end, and I'd like to keep it that way for now.

## Bug Reports

Bug reports are absolutely welcome and appreciated.

If you encounter:
- crashes
- incorrect behavior
- installation issues
- Unraid-specific problems

please open an issue with as much detail as you can provide — your transfer
mode (local / SMB), the disc format (DVD / Blu-ray / UHD), and the relevant
lines from `/data/mkvauto/logs/` all help. Clear reports directly improve the
quality and stability of the project.

## Suggestions & Feedback

Ideas and feedback via issues are welcome, with the understanding that not
every suggestion will be implemented. Design and architectural direction
ultimately stay with me.

## Pull Requests

This repository is a generated release mirror: each release replaces the tree
wholesale from a private working repository, so a pull request opened here has
nothing to merge into and will be closed. Beyond the mechanics, I'm not taking
external code contributions right now — development is centralized so I can
stand behind every line that ships.

That said, if you've fixed something locally, describing the fix (or attaching
a patch) to an issue is genuinely useful. I may reimplement it upstream, with
credit.

## Forks & Modifications

MKV Auto is open source under the AGPL-3.0 license. You are free to use,
modify, and redistribute it — including modified versions — under the terms
of that license. All I ask is that forks make clear they are not official
MKV Auto releases.

## Security Issues

If you believe you have found a security vulnerability, please do not open a
public issue. Instead, follow the instructions in SECURITY.md.

---

Thank you for helping improve the project through thoughtful feedback and bug
reports.
